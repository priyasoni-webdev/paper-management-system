# Paper Management System

A simple web app to manage paper supply.

### Features:
- Paper type fetched from MySQL database
- Rate auto-fetched using data-rate attribute
- Total price calculated in real-time with JavaScript
- Form validation (max 10 ream)

### Tech Stack:
HTML, CSS, JavaScript, PHP, MySQL, XAMPP

### How to run:
1. Import SQL file in phpMyAdmin
2. Put folder in htdocs
3. Run on localhost
